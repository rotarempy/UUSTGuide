# Карта кампуса

Исправлена ошибка компилятора Kotlin «Type checking has run into a recursive problem» в `MainActivity.kt`: у функций, которые создают элементы интерфейса и вызывают друг друга, теперь явно указаны возвращаемые типы.

Главный экран использует два файла: `app/src/main/assets/map1.svg` (общая карта) и `map2.svg` (планы этажей). Доступные схемы определяются по группам `<g id="N-F">`. Сейчас в `map2.svg` находятся этажи 1–5 корпуса 6.

- Нажатие на корпус на общей карте открывает список доступных этажей. Выбор этажа показывает только его схему; кнопка «Этажи корпуса» и системная кнопка «Назад» возвращают к списку. Если схем пока нет, показывается сообщение о разработке. Кнопки 1–9 внизу по-прежнему приближают корпуса, «Все» возвращает обзор. В режиме этажей при выборе корпуса без схемы текущего этажа появляется карточка «Схема этажа в разработке».
- Карту можно двигать одним пальцем и масштабировать двумя пальцами. Каждый новый быстрый переход или поиск выставляет масштаб пункта назначения заново; после перехода карта остаётся свободной для ручного изменения масштаба в разумных пределах: уменьшение ограничено размером общего плана, увеличение — размером значка на схеме.
- При смене режима обзор начинается с целой карты. Ручное перемещение ограничено границами холста, чтобы карта не исчезала за пределами экрана.
- Поиск по номеру, например `6-101` или `101`, открывает подробный вид, выбирает этаж, подсвечивает кабинет и приближает его. Если номер найден в нескольких корпусах или этажах, сначала предлагается выбрать корпус и этаж. Кнопка «Все» убирает подсветку и возвращает общий обзор подробной карты.
- В подробном режиме фильтры показывают или скрывают номера кабинетов, лестницы, туалеты, буфеты, кофе, гардероб и места отдыха. Фильтр действует сразу на все этажи.

Верх экрана теперь занимает две строки. Поиск открывается значком в заголовке в компактном окне с цветами и кнопками приложения. В строке режимов находятся кнопки «Карта»/«Этажи»; в подробном режиме рядом находятся выбор этажа через меню и кнопка «Слои». Она открывает нижнюю панель с отдельными переключателями всех перечисленных фильтров. Нижний быстрый выбор корпусов остался на месте.

Тема приложения следует системной настройке устройства. Светлая палитра задана в `res/values/colors.xml`, тёмная — в `res/values-night/colors.xml`; обе используются экраном, поиском, фильтрами и WebView с картой. В `values-night/themes.xml` настроен цвет значков системной строки состояния. Ручная кнопка переключения темы удалена. При системной смене темы Android пересоздаёт экран с сохранением режима карты, этажа, корпуса, поиска и фильтров.

Для новых планов добавляйте в `map2.svg` группу `<g id="N-F">` (N — номер корпуса, F — номер этажа). Внутри неё используйте группы `Rooms`, `Stairs`, `WC`, `Buffets`, `Coffee`, `Wardrobe`, `Rest` (допускаются суффиксы `_2`, `_3`), а подписи кабинетов — как SVG `<text id="room-N-XXX">` с читаемым текстом номера. Если в Figma имена меняются, фильтры и поиск нужно будет обновить в `MainActivity.kt`.

У двух присланных SVG размеры холста немного различались. В `map2.svg` задан тот же `viewBox`, что и у `map1.svg`: `0 0 10165 4306`. При следующем экспорте из Figma лучше использовать две копии одного Frame с точно одинаковыми размерами.

Архив не содержит локальные кэши Gradle и результаты сборки. Ресурсы иконки `ic_launcher` из актуального проекта сохранены.
